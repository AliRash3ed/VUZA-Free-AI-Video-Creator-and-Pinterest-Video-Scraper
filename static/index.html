零成本自动化视频生成工具

输入一个悬疑点子或旁白脚本，VUZA 会自动生成分镜关键词、用 Seedream 生成镜头画面、生成中文旁白、添加字幕并合成竖屏短视频。

当前默认: 中文悬疑剧情模板、Seedream 4.5 AI 生图、中文配音、高留存字幕、9:16 竖屏输出。

使用流程: 先在 API 设置里填 AI 文本密钥和豆包 Seedream 生图密钥， 然后输入悬疑主题，生成脚本，最后点击“生成视频”。

🔒 所有密钥只保存在你的浏览器本地，不会发给无关第三方。

AI 接口（OpenRouter / DeepSeek / OpenAI 兼容）

DeepSeek 官方：地址填 https://api.deepseek.com，模型填 deepseek-v4-pro。OpenRouter：地址用 chat/completions，模型通常是“厂商/模型”。
